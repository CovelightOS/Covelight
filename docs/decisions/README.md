# Architecture Decision Records

One file per decision, numbered, never deleted. Format: **Context** (what forced a choice) / **Decision** (what we chose, stated plainly) / **Consequences** (positive AND negative — an ADR with no listed costs wasn't thought through) / **Status** (Proposed / Accepted / Superseded-by-NNNN).

Write an ADR when a decision is *made* — including reversals of earlier decisions (see 0001). If a debate keeps recurring in issues or chat, that's the signal it needs an ADR.
